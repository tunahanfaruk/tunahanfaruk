## What it is

Most "AI agent" products hand you a fixed org chart: a researcher, a writer, a
reviewer, forever. Xorviex doesn't. You describe an outcome — *"find every
distributor in the DACH region selling a competing product and tell me how our
pricing compares"* — and Xorviex **designs the team for that job**: how many
agents, what each one is responsible for, what each one is allowed to touch.

Then the team goes to work. The agents don't just read and summarise — they
search the live web, open pages, pull real numbers, and act inside the tools
you already use. Every result is reviewed by a separate AI before it reaches
you or the outside world.

## What it does for you

### 🧠 It builds the team, you don't
No role picker, no agent-count slider, no workflow to wire up. You write the
goal in a sentence; the org chart comes back designed for it.

### 🛠️ It acts, not just advises
Agents research on the live web — search, read pages, scrape, track brand and
news mentions, follow metrics over time — and then *do* the thing: send the
Slack message, open the pull request, update the Notion page, draft the email,
publish the post.

### 👁️ Nothing ships unreviewed
Every agent's output is graded by a separate AI against what that agent was
actually asked to do. Weak work gets sent back with specific notes and redone.
If it keeps failing, it comes to you instead of quietly shipping.

### 📈 It remembers what it measured
Numbers Xorviex collects stay on the record, so "is this going up or down?"
is answerable months later. And when there isn't enough history to answer,
it says so — you'll never get an invented percentage.

### 🔁 It can run on a schedule
Turn any mission into a recurring one — a weekly competitor sweep, a daily
inbox triage, a monthly report — and it spawns a fresh run on its own.

### 💬 You run it by talking to it
Command Chat is a conversation over your whole workspace: start missions,
rewrite an agent's brief mid-flight, update what the team knows about your
company. If your request is ambiguous, it asks you rather than guessing.

## Built to be trusted with real access

Giving an AI the ability to *act* only works if the guardrails are real:

- **An independent reviewer on every output** — the agent that does the work is
  never the one that approves it.
- **Least access by default** — an agent can only reach the integrations you
  connected, and only for the workspace it's running in.
- **Your accounts stay yours** — every connected credential is encrypted, and
  code changes arrive as a pull request for you to review, never a direct push.
- **Two-factor on by default**, with recovery codes — not an opt-in setting
  buried in a menu.
- **Honest numbers** — a figure without a basis for comparison is reported as
  "not enough history", never rounded up into a story.

## Pricing

Work is measured in **Operation Units (OU)** — one unit is one thing an agent
did: a page scraped, a message sent, a draft written, a review performed.

| | Starter | Scale | Enterprise |
|---|---|---|---|
| OUs / month | 15M | 100M | Custom |
| Concurrent missions | 5 | 25 | Unlimited |
| Model quality | Standard | + Frontier models | Custom |

For scale: a real mission — one goal, four to six agents, live research plus a
review on every output — costs around **1.3M OUs** start to finish.
